# 🍽️ Restaurant Order & Billing System

A web-based Restaurant Order and Billing System that allows users to browse menu items, add items to a cart, place orders, generate bills, and maintain order history.

## 🚀 Features

- 📋 View restaurant menu
- 🛒 Add and remove items from cart
- 💰 Automatic bill calculation
- 🧾 Generate customer bills
- 📜 View order history
- 💾 Store restaurant data using SQLite
- 🌐 Interactive web interface
- 🔧 Backend server using Node.js

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- SQLite
- npm
